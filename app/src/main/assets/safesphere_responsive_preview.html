22. Profile
Core Capabilities

Everything a Family Needs — Nothing They Don't

Built on consent, transparency, and intelligent monitoring. No hidden tracking. No black-box alerts.

✈️
Consent-Based Travel Approval
Student requests solo travel. Parent approves or declines. A SafeSphere gate prevents journey start without approval.
🎯
Multi-Factor Driver Verification
Before every journey: Driver face, ID, vehicle number, and booking reference are all verified via ML Kit + demo database.
📍
Live Journey Monitoring
Real-time GPS tracking with expected vs actual route comparison. Adaptive update intervals for battery efficiency.
🏠
Context-Aware Safe Zones
Geofences with schedule awareness. A college zone exit at 4:12 PM is "Expected". The same at 11:20 AM is "Check Required".
🔑
Emergency Keys System
Normal PIN + secret Duress PIN. Shake gesture trigger. The duress PIN shows normal UI while silently alerting parents.
📷
Consent-Based Camera Check
Parent can request a camera check. Student sees the request and must allow it. Camera never activates remotely.
💬
I'm OK + WhatsApp Sharing
One-tap "I'm OK" creates a timestamped check-in and optionally sends a pre-filled WhatsApp message to parents.
📋
Explainable Safety Timeline
Every event — from journey start to destination arrived — is logged with timestamps, reasons, and actions taken.
⚡
Multi-Signal Risk Engine
Combines route deviation, unexpected stops, check-in silence, and sensor data into clear states: NORMAL → CHECK_REQUIRED → ELEVATED → EMERGENCY.
📘
Auto-Generated Parent Guide PDF
One button generates a complete family safety guide. Emergency PINs are hidden by default, shown only after biometric auth.
